## 🚀 Featured Project

### 🛡️ VeriTrust AI

**AI-Powered Insurance Policy Analysis & Blockchain-Based Document Verification Platform**

VeriTrust AI combines AI-powered document analysis with blockchain-based verification to help users understand insurance policies and verify document integrity.

**Core workflow:**

`Document Upload → OCR → AI Processing → Policy Analysis → Risk & Coverage Insights → Blockchain Verification`

**Technology Stack:**

React.js • FastAPI • Python • Tesseract OCR • LangChain • Ollama • Solidity • Polygon • IPFS
